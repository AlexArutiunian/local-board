# Local Board

Совместная realtime-доска для занятий: преподаватель может одновременно работать с iPad + Apple Pencil и с компьютера, ученик подключается по отдельной ссылке, а общий canvas синхронизируется через WebSocket.

Проект сейчас рассчитан на один Linux-хост, но frontend использует same-origin HTTP/WebSocket и работает через LAN, HTTPS/WSS reverse proxy или Cloudflare Tunnel.

## Что уже есть

- dashboard досок на `/`: создать новую, открыть прошлую или войти по 4-значному коду;
- realtime-комнаты: snapshot/reconnect, `ack`, `op_id`, dedupe и локально-оптимистичный UI;
- **роли участников: Преподаватель / Ученик**, имя и устройство (`iPad`, `Компьютер`, телефон/планшет);
- dashboard открывает доски как преподаватель;
- кнопка **Поделиться** у преподавателя даёт две ссылки:
  - **ученику** — вход с ролью «Ученик»;
  - **преподавателю** — для собственного второго устройства, с тем же именем/ролью;
- список подключённых людей сгруппирован по ролям и показывает устройство каждого подключения;
- профиль можно изменить кликом по своему бейджу в верхней панели;
- роли сейчас являются **идентичностью/UX, а не авторизацией**: перед публичным teacher-only permissions нужны server-issued owner/invite credentials;
- **компактный activity log занятия**: сервер пишет join/leave, законченные штрихи и важные board actions с точным временем, именем, ролью и устройством автора;
- `stroke.begin` и многочисленные `stroke.append` в лог не попадают — один законченный штрих = одна строка на диске;
- форма законченного штриха сохраняется внутри этой строки в компактном replay-представлении (`zlib + base85`), поэтому историю можно будет воспроизводить даже после стирания/очистки доски;
- activity-файлы делятся по комнатам и дням UTC и **никогда не загружаются целиком в RAM**;
- Apple Pencil ink + pressure, WebKit recovery, palm rejection;
- **Apple Pencil нажимает кнопки, popover-меню и toolbar как палец** — для Safari есть отдельный Pencil-click fallback;
- default iPad input: Pencil пишет, палец редактирует картинку под ним или двигает canvas, два пальца делают pinch;
- выбранная пальцем картинка не отбирает Pencil у ручки: можно двигать фото пальцем и продолжать писать Pencil;
- tap пальцем по пустому месту закрывает редактирование картинки;
- второй палец во время drag картинки отменяет только текущий drag и сразу переводит оба контакта в pinch/pan;
- отдельный toggle **«рисовать мышью/пальцем»** для ученика без Pencil;
- в direct-ink режиме Pen/Eraser пальцем имеет приоритет даже над картинкой, поэтому можно писать прямо поверх вставленного задания; второй палец всё равно переводит жест в pinch;
- ластик Pencil/мышью, а при direct-ink — и пальцем;
- **полноценный Select (`V`)** для рукописи и изображений:
  - мышь, Apple Pencil и **один палец** на сенсорном устройстве работают как указатель выбора;
  - drag по пустому месту создаёт marquee только после threshold;
  - после выделения можно тянуть **за любую точку внутри синей общей рамки**, а не обязательно попадать точно в линию;
  - два пальца в Select всё равно немедленно возвращаются к pinch/pan;
  - Shift multi-select, `Ctrl/Cmd+A`, `Esc`, Delete/Backspace;
  - для рукописи/смешанной группы появляется touch-friendly панель **Копировать / Вставить / Дубликат / Удалить / Готово**;
  - `Ctrl/Cmd+C/V/D` работает не только для картинки, но и для выделенной рукописи/смешанной группы;
- ПКМ + drag — временное marquee из любого инструмента; простой ПКМ-клик ничего не делает;
- изображения: file picker, drag&drop, clipboard paste; bytes хранятся отдельно от JSON/WebSocket state;
- finger tap по картинке → контекстное меню; finger drag → move;
- image actions: crop, copy, duplicate, front/back, reset crop, delete, «Готово»;
- non-destructive crop с 8 handles, realtime persistence;
- Undo/Redo рукописи, стирания, вставки и удаления изображений; дублированная рукопись также регистрируется как созданный stroke;
- **общий фон/разлиновка доски**, синхронизируемый и сохраняемый в snapshot:
  - чистый лист;
  - точки;
  - клетка;
  - мелкая клетка с major lines;
  - линейка;
  - Cornell;
  - изометрическая сетка;
- пять оттенков бумаги: белый, тёплый, серый, голубой, мятный;
- role-neutral auto-follow за активным пишущим;
- auto-follow и auto-scale — две независимые локальные кнопки;
- `⌖` — перейти к последнему месту письма;
- zoom percentage показывает реальный масштаб, клик возвращает 100% вокруг текущего viewport;
- PNG/Clear спрятаны в `⋯`;
- атомарное JSON-сохранение досок и отдельное локальное хранение изображений.

## Быстрый запуск

```bash
git clone https://github.com/AlexArutiunian/local-board.git
cd local-board
bash scripts/run.sh
```

Локально:

```text
http://127.0.0.1:8000
```

В LAN:

```bash
hostname -I
```

и открой, например:

```text
http://192.168.1.50:8000
```

Через Cloudflare Quick Tunnel (для тестов из интернета):

```bash
cloudflared tunnel --url http://localhost:8000
```

Пока `cloudflared` запущен, выданный `https://....trycloudflare.com` проксирует тот же Local Board, включая WSS.

> 4-значный код, query `role=teacher` и текущие role labels не являются защитой. Перед постоянным публичным использованием нужно закрыть dashboard и добавить секретные owner/invite credentials — см. `docs/deployment.md`.

## Роли и несколько устройств

Первый вход попросит выбрать роль и имя. Профиль запоминается в браузере.

Рекомендуемый сценарий занятия:

1. преподаватель создаёт/открывает доску через dashboard;
2. на компьютере нажимает **Поделиться → Ссылка преподавателя** и открывает её на iPad — оба подключения отображаются как преподаватель с тем же именем, но с разными устройствами;
3. ученику отправляет **Ссылка ученику**;
4. в верхней панели по счётчику участников можно увидеть, кто подключён и с какого устройства.

## Activity log занятия

На сервере сохраняется не сетевой шум, а семантические действия. Для письма одна запись создаётся только после `stroke.end` и содержит:

```text
время начала + длительность
роль / имя / устройство
stroke_id
цвет / толщина / pointer type
число точек
bbox — где на доске был штрих
path_z — сжатая форма штриха для будущего replay
```

Также пишутся `join`, `leave`, удаление/возврат/перемещение штрихов, операции с картинками, смена фона и очистка доски.

Логи append-only и шардируются по UTC-дню:

```text
~/.local/share/local-board/activity/<room>/2026-08-22.jsonl
```

История не кешируется в приложении. В RAM хранится только время начала нескольких **активных** штрихов; таблица дополнительно ограничена 2048 записями как защита от утечки при оборванных клиентах.

## Фон

Кнопка с листом/линиями в нижнем toolbar открывает выбор разлиновки и цвета бумаги. Изменение является shared board state: новый фон сразу видят все участники и он остаётся после reload/reconnect.

## Управление

| Действие | Управление |
|---|---|
| Рисование Apple Pencil | Pen tool; выбранная пальцем картинка не отбирает Pencil у ручки |
| Нажатие UI Pencil | обычный короткий tap Pencil по кнопке/menu item |
| Редактировать картинку на iPad | tap пальцем по картинке → меню; drag → перемещение |
| Выйти из редактирования картинки | tap пальцем по пустому canvas или «Готово» |
| Рисование пальцем/мышью | включить direct ink → Pen → один палец / ЛКМ |
| Pan | direct ink выключен: один палец/мышь; либо Pan tool |
| Zoom | два пальца / колесо; в Select два пальца тоже остаются pinch/pan |
| Ластик | `E`; Pencil/мышь, а с direct ink — один палец |
| Select | `V`; мышь / Apple Pencil / один палец |
| Marquee | drag по пустому месту после threshold |
| Переместить выделение | drag по штриху либо по пустому месту внутри общей синей рамки |
| Быстрое marquee | удерживать ПКМ и тянуть |
| Multi-select | `Shift + click/drag` |
| Выделить всё | `Ctrl/Cmd+A` |
| Копировать/вставить выбор | контекстная панель или `Ctrl/Cmd+C`, `Ctrl/Cmd+V` |
| Дублировать выбор | контекстная панель или `Ctrl/Cmd+D` |
| Удалить выбор | контекстная панель или `Delete` / `Backspace` |
| Ручка | `P` |
| Pan tool | `H` |
| Изображение | Image / drag&drop / paste |
| Crop | выбрать фото → Обрезать → handles → Готово/Отмена |
| Undo/Redo | `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z` |

## Данные

```text
~/.local/share/local-board/boards/     # JSON текущего состояния
~/.local/share/local-board/assets/     # изображения по комнатам
~/.local/share/local-board/activity/   # компактная история действий по дням
```

Свой каталог:

```bash
LOCAL_BOARD_DATA_DIR=/path/to/data bash scripts/run.sh
```

Другой порт:

```bash
LOCAL_BOARD_PORT=9000 bash scripts/run.sh
```
